What is a Decision Network?

A Decision Network (also called an influence diagram) extends a Bayesian network with decision and utility nodes. It models decision-making under uncertainty: we don't know what will happen, so we weigh each outcome by how likely it is (probability) and how good or bad it is (utility). The rational choice is the one with the highest expected utility.

⬭ Chance Node

An uncertain event with probabilities, e.g. Weather: Sunny 70%, Rainy 30%.

◇ Utility Node

The value of an outcome, e.g. +10 for staying dry, −10 for getting soaked.

Expected Utility

Expected utility is the average payoff of a decision if you could repeat the situation many times, weighting each outcome by its probability.

EU(D) = Σ P(S) × U(D,S)
  • P(S) – probability that state S happens.
  • U(D,S) – utility of taking decision D when state S happens.
  • EU(D) – expected utility of decision D (sum over all states).

Value of Information

Value of Information (VOI) is how much better your expected result gets if you learn something before deciding. Example: a perfect weather forecast tells you Sunny or Rainy first, so you can choose the best action for each case.

The difference is the Expected Value of Perfect Information (EVPI). If a forecast costs more than EVPI, it isn't worth buying.

Theory Notes

Decision Networks

A graph with chance, decision and utility nodes. Edges show influence or information available before a decision.

Utility Functions

A utility function maps each outcome to a number showing how much the agent prefers it. Higher is better.

Multi-attribute Utility

When outcomes have several attributes, combine them, often as a weighted sum U = Σ wᵢ·uᵢ.

Expected Utility

EU(a) = Σ P(s)·U(a,s). A rational agent picks the action that maximises EU (MEU principle).

Value of Information

VOI = expected utility with the information − expected utility without it. It is never negative.

Decision-making under Uncertainty

The agent doesn't know the true state, so it uses probabilities for beliefs and utilities for preferences.
